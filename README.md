## 📌 Overview

A modern, interactive personal portfolio website built with pure **HTML, CSS & Vanilla JavaScript** — no frameworks, no dependencies. Designed with a minimal dark aesthetic, glassmorphism UI, and smooth micro-animations that create a premium, award-worthy first impression.

> 🎯 Currently learning **Prompt Engineering** alongside my B.Tech CSE degree.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🌌 **Interactive Canvas** | Animated particle constellation background with mouse-reactive nodes |
| 🖱️ **Custom Cursor** | Glowing cursor glow that follows mouse movement |
| 🪟 **Glassmorphism UI** | Frosted glass project cards with depth and blur effects |
| 📱 **Fully Responsive** | Optimized for mobile, tablet, and desktop |
| 🎬 **Smooth Animations** | Intersection Observer scroll reveals, hover micro-interactions |
| 🔢 **Live Counters** | Animated project/tech counters on scroll |
| 🌙 **Dark Minimal Theme** | Deep obsidian palette with subtle cyan/violet accents |
| 📬 **Contact Section** | Social links, email, and GitHub profile |

## 🚀 Getting Started

No build step required. Just open `index.html` in your browser:

```bash
# Clone the repo
git clone https://github.com/SakshamKannojia/PORTFOLIO.git

# Navigate into the folder
cd PORTFOLIO

# Open in browser (Windows)
start index.html

# Or with Live Server in VS Code
# Right-click index.html → Open with Live Server
```

## 🌐 Deployment

This portfolio is deployed via **GitHub Pages**.

To deploy your own fork:
1. Push to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to `main` branch → `/ (root)`
4. Your site will be live at `https://<username>.github.io/<repo-name>`
